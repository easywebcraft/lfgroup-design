## トップの写真の季節の切り替え（人生の四季）

- 2026-10-05、お客さまから「トップの写真を春→夏→秋→冬とループさせたい」と要望があり、試作で確かめてからトップに入れた

- 先に「同じ家族の1年」（春＝hero.jpg、夏・秋・冬で場面とポーズを変えた同じ家族）で作り、「人生の四季」と見比べて、こちらに決めた（同じ家族の秋・冬の写真は外した）
- 写真は ChatGPT で、今の hero.jpg を添付して生成。指示が足りず、夫婦の向きが3枚とも同じ・秋の子どもが女の子・年齢が若すぎる／離れすぎる、となったので、秋と冬を作り直した。冬は70代だと秋から離れすぎるので60代前半にした
- 夏に hero.jpg を使うと、それまでのトップの写真と同じに見えるので使わない（hero.jpg は事業内容ページで使っている）
- 最初の演出が終わってから約3.5秒で最初の切り替え、そのあとは6秒ごと。切り替え方はゆっくりクロスフェード（斜めのワイプ・やわらかいワイプ・白く溶ける・縦のスリットと見比べて決定）。最後の写真（三世代の春）から最初の写真へ戻るときだけ、一区切りが分かるよう、白へ消えて白を少し見せてから現れる（約3.5秒。そのぶん最初の写真を長く見せる）
- 季節の名前のボタン・一時停止ボタンは、お客さまの希望で付けない。「動きを減らす」設定の端末では自動で切り替えない
- スマホで顔が切れないよう、見せる位置は season.css で写真ごとに合わせている
- 動きは `src/season.css`・`src/season.js`（`build.py` が style.css・main.js に足す）
- /season/・/life/ は試作のときのURLで、今はトップへ移るだけのページ

## 見出しの句読点（2026-10-08 松本さん）
